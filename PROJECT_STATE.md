## Architecture
- Next.js 15 App Router + TS + Tailwind v3 + React 19 + R3F 9 + maath (tokens in tailwind.config.ts + CSS vars in globals.css)
- GSAP+ScrollTrigger = scroll-driven; Framer Motion = pointer-driven; never same property
- One Lenis instance (components/layout/SmoothScroll.tsx) synced to gsap.ticker
- R3F reads lib/scroll-state.ts (mutable heroScroll.progress + servicesScroll.progress written by ScrollTrigger)
- Section 3D bands: ONE lazy R3F canvas per band (components/sections/services/ServicesScene.tsx pattern): IntersectionObserver rootMargin 600px mounts, 80px toggles frameloop always/demand, dpr cap 1.5, antialias off. Contents: procedural nebula shader (2 radial glows, no textures), 150 instanced drift cubes, 4 larger fragment cubes. Mobile: NO WebGL in bands — CSS gradient pocket + 14 CSS drift dots (hero keeps its canvas)
- Supabase later: inquiries (CRM-lite status field), services, projects tables; RLS; inserts via app/api/contact route with service role key
